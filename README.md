# 🎓 Exercícios de Lógica e Programação em Java

Este repositório contém os exercícios e práticas desenvolvidos durante as aulas do curso de **Análise e Desenvolvimento de Sistemas**.

## 🚀 Conteúdo do Repositório

- **Práticas**:
  - Pequenos scripts e desafios de lógica desenvolvidos ao longo das disciplinas.

- **Calculadora Trabalhista (`Aula_Engenharia.java`)**: Aplicação em Java com interface interativa (`JOptionPane`) para cálculo de:
  - Dobro de salário
  - Cálculo de 1/3 de férias
  - Dedução de adiantamento
  - Cálculo de horas extras

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java
- **Interface de Entrada/Saída:** `javax.swing.JOptionPane`
- **IDE:** IntelliJ IDEA
- **Controle de Versão:** Git / GitHub
